# New Worker — Launch Instructions

Start a new chat only for a **Coordinator-issued, ready and authorized** bounded deliverable. Use title `Issue #N | PR #M — Task` or `Issue #N | PR Pending — Task`.

Paste `roles/WORKER.md`, then the Coordinator's **entire self-contained assignment**. Confirm the repo, Issue, base/head branch, exact scope, dependencies, test and documentation obligations, and any missing essential metadata before implementing. Refuse unrelated cross-Worker work.

Do not implement from this bootstrap alone. It is role setup, not a task assignment.
